### Added — Generic Structural Folding Model

* Defined **GenericContainerStarmap** as the canonical structuralization interface.

* Introduced the concept of the:

> **Structuralization Boundary**

between domain-specific representation and domain-independent Structural Intelligence mechanisms.

* Defined:

> **Policy-Guided Structuralization**

as the process of constructing structurally meaningful representations under explicit policies.

* Generalized Structural Folding beyond one application domain.

* Defined the canonical transformation:

> **Similarity → Shared Structure → Difference Localization → Dispatch**

* Defined **Metric Differential Structure** as the deeper abstraction behind tree-based implementations.

* Retained **Metric Differential Tree** as a canonical practical runtime embodiment.

### Added — Core and Delta

### Design Decisions

* Kept the v1.0 repository focused on theory, framework, examples, and visual explanation.

* Deliberately did **not** add a Java demo to the initial GFSFUI repository.

* Preserved a text-first Collective Learning path.

* Kept domain-specific runtime implementations separable from the general framework.

* Treated Stock Market, Biomedical, and CallingGraph as complementary demonstrations rather than attempts to force one domain implementation onto all others.

---

### Clarified

* GenericContainerStarmap is a structural interface, not a claim that every domain has one unique optimal representation.

* Metric Differential Tree is a canonical implementation, not the only valid topology.

* CCC is not limited to geometric centroid behavior.

* DNA relations do not automatically imply causality.

* 3-Cat Structural Learning does not imply that exactly three observations are statistically sufficient.

* Counter-Evidence is not equivalent to simple negative scoring.

* Structural Equivalence is not necessarily Exact Identity.

* Universal Naming is not required before useful Structural Folding can begin.

* CallingGraph does not need to contain all program semantics to be useful as a Foldable structural representation.

* GFSFUI is a general research and engineering framework, not a completed universal theory of intelligence.
